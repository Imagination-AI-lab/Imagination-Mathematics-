Key Question: Which sequence grows by adding the EXACT SAME NUMBER each time?
Fibonacci adds prior terms; squares add odd increments; powers multiply. Only ONE adds a constant $d$:
That is an Arithmetic Progression (A.P.)!

Definition: Arithmetic Progression (A.P.)

A sequence where each term after the first is obtained by adding a fixed number $d$ (the common difference) to the preceding term.

General Form: $a,\; a+d,\; a+2d,\; a+3d,\; \dots,\; a+(n-1)d$ • Mentored by Santanu Sir

The General Term: $a_n = a + (n - 1)d$

Why is the coefficient $(n - 1)$? Because the 1st term requires 0 steps of $d$!

Formula: $a_n = a + (n-1)d$
Step-by-step Pattern Discovery
$T_1 = a$ $= a + \mathbf{0} \cdot d$
$T_2 = a + d$ $= a + \mathbf{1} \cdot d$
$T_3 = (a + d) + d$ $= a + \mathbf{2} \cdot d$
$T_4 = (a + 2d) + d$ $= a + \mathbf{3} \cdot d$
$T_n =$ $a + \mathbf{(n - 1)}d$

In analytical geometry, $y = mx + c$. Here $a_n = d \cdot n + (a - d)$. An A.P. is a linear function sampled over natural numbers $n \in \mathbb{N}$!

Sum of First $n$ Terms: $S_n = \frac{n}{2}[2a + (n-1)d] = \frac{n}{2}(a + l)$

Young Gauss's discovery: pairing symmetric terms from opposite ends!

Young Gauss's Pairing ($1 + 2 + \dots + 100$) Pairing active
$S_n = a + (a+d) + \dots + (l-d) + l$ (1)
$S_n = l + (l-d) + \dots + (a+d) + a$ (2, reversed)
$2S_n = n(a+l) \implies S_n = \frac{n}{2}(a+l)$ $\text{Substitute } l = a+(n-1)d$
