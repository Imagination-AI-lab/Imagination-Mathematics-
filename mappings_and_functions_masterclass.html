Theory of Mappings (চিত্রণ)

"A rule connecting two sets such that every input has a unique output: from Injective and Surjective types to Invertibility and Composition."

Mathematical Definition of Function $f: A \to B$:
$$\forall x \in A, \exists!\, y \in B \text{ such that } f(x) = y$$
Domain (প্রক্ষেত্র): Set $A$
Co-domain (উপপ্রক্ষেত্র): Set $B$
Range (পাল্লা): $f(A) \subseteq B$

Classification Breakdown & Counting
1. Injective (One-One / একৈক): ✓ True
$x_1 \neq x_2 \implies f(x_1) \neq f(x_2)$ or $f(x_1) = f(x_2) \implies x_1 = x_2$.
Otherwise, it is Many-One (বহু-এক).
2. Surjective (Onto / উপরিচিত্রণ): ✓ True
$\text{Range } f(A) = \text{Co-domain } B$. $\forall y \in B, \exists x \in A$ s.t. $f(x) = y$.
If $\text{Range } f(A) \subset B$, it is Into (অন্তঃচিত্রণ).
3. Bijective (একৈক-উপরিচিত্রণ): ✓ True
Both One-One AND Onto. Essential for Invertibility!
Counting Formulas ($|A| = m, |B| = n$):
• Total Mappings: $n^m$
• One-One Mappings: $^n P_m$ (if $n \ge m$, else 0)
• Bijective Mappings (when $m = n$): $n!$
💡 For $A \to A$ on a finite set: One-One $\iff$ Onto $\iff$ Bijective.
Condition of Function: Every element of Domain must have exactly ONE image in Co-domain. • Santanu Sir

Inverse Mapping (বিপরীত চিত্রণ - $f^{-1}$)

An inverse mapping $f^{-1}: B \to A$ exists if and only if $f: A \to B$ is a Bijective (One-One & Onto) function!

$y = f(x) \iff x = f^{-1}(y)$
Interactive Dual Arrow Flow: $f$ vs $f^{-1}$
Why One-One is Needed:

If Many-to-One, reversing would map 1 element to multiple outputs, which violates the definition of a function!

Why Onto is Needed:

If Into, some elements in $B$ have no pre-image, leaving unmapped elements in $\text{Dom}(f^{-1})$!

Board Exemplar: Algebraic Finding of $f^{-1}(x)$
✓ Fundamental Invertibility Identity:
$(f^{-1} \circ f)(x) = x = I_A \quad \text{and} \quad (f \circ f^{-1})(y) = y = I_B$
Theorem: If $f$ is bijective, its inverse $f^{-1}$ is unique and $(f^{-1})^{-1} = f$. • Santanu Sir

Composition of Mappings (চিত্রণের সংযোজন - $g \circ f$)

Let $f: A \to B$ and $g: B \to C$. The composite mapping $g \circ f: A \to C$ is defined by $(g \circ f)(x) = g(f(x))$.

Condition: $\text{Range}(f) \subseteq \text{Domain}(g)$
3-Set Cascade Pipeline: $A \xrightarrow{f} B \xrightarrow{g} C$
Choose input $x \in A$:
💡 Shortcut Direct Path: $(g \circ f)(x)$ skips the intermediate station $B$ directly taking $x \in A$ to $g(f(x)) \in C$.
Essential Theorems & Properties
1. Non-Commutative:
$g \circ f \neq f \circ g \quad \text{in general!}$
Even their domains and co-domains usually differ.
2. Associative Property:
$h \circ (g \circ f) = (h \circ g) \circ f$
Whenever compositions are well-defined.
3. Preservation of Bijections:
If $f$ and $g$ are both Bijective, then $g \circ f$ is also Bijective!
4. Socks-and-Shoes Reversal Rule:
$(g \circ f)^{-1} = f^{-1} \circ g^{-1}$
Order reverses when taking the inverse of a composite!
Identity compositions: $f \circ I_A = f$ and $I_B \circ f = f$.
Example: Let $f(x) = 2x$ and $g(x) = x^2$. Then $(g \circ f)(x) = 4x^2$, but $(f \circ g)(x) = 2x^2$. • Santanu Sir
