1. Reflexive Relation (স্বসম সম্বন্ধ)

A relation $R$ on a set $A$ is Reflexive if $\forall a \in A,\; (a, a) \in R$. Every single element must be related to itself!

DiGraph Visualization (Self-Loops Required)
Not Reflexive
Graphical Criterion:

In a directed graph, $R$ is reflexive if and only if every node possesses a self-loop. In an adjacency matrix, the entire main diagonal must be 1.

Identity vs Reflexive:

Identity $I_A$ contains only $(a,a)$. Reflexive must have all $(a,a)$ and may include extra pairs!

Irreflexive (অস্বসম):

$(a, a) \notin R$ for every $a \in A$. Example: Strict inequality "$x < y$" on $\mathbb{R}$.

Example: On straight lines in a plane, "is parallel to" ($\parallel$) is reflexive ($L \parallel L$), but "is perpendicular to" ($\perp$) is NOT reflexive ($L \not\perp L$). • Santanu Sir

2. Symmetric & Anti-Symmetric (প্রতিসম ও বিপ্রতিসম সম্বন্ধ)

Symmetric: $(a, b) \in R \implies (b, a) \in R$ • Anti-symmetric: $(a, b) \in R \land (b, a) \in R \implies a = b$.

Symmetric condition: $R = R^{-1}$

Matrix Transpose Property:
$R \text{ is symmetric} \iff M_R = M_R^T$

Subset Relation ($A \subseteq B$): If $A \subseteq B$ and $B \subseteq A \implies A = B$. Hence, it is Anti-symmetric!
Note: A relation can be both Symmetric and Anti-symmetric simultaneously (e.g. Identity relation $I_A$). • Santanu Sir

3. Transitive Relation (সংক্রমণ সম্বন্ধ)

A relation $R$ is Transitive if whenever $(a, b) \in R$ and $(b, c) \in R$, then the direct shortcut pair $(a, c) \in R$.

✓ Transitive: Satisfied
Highway Direct Path Verification a → b → c ⇒ a → c
Classic Board Trap ($L_1 \perp L_2$):
In a 2D plane: $L_1 \perp L_2$ and $L_2 \perp L_3 \implies L_1 \parallel L_3 \implies (L_1, L_3) \notin R$!
Hence, perpendicularity is NOT Transitive!
Interactive Transitive Inspector on $A = \{1, 2, 3\}$

💡 Vacuously Transitive: If there are NO two pairs such that the second coordinate of the first matches the first coordinate of the second (i.e. No chain $(a,b) \land (b,c)$ exists), the condition is vacuously satisfied! (e.g. $R = \{(1, 2)\}$ is Transitive).
To disprove transitivity, you only need to show ONE counterexample pair $(a,b) \in R$ and $(b,c) \in R$ where $(a,c) \notin R$. • Santanu Sir

4. Equivalence Relations & Classes (সমতুল্যতা শ্রেণি)

A relation $R$ is an Equivalence Relation if it is simultaneously: Reflexive + Symmetric + Transitive!

$R \equiv \text{Ref} \cap \text{Sym} \cap \text{Trans}$
The Equivalence Triad Check
1. Reflexivity: $\forall a, (a,a) \in R$ ✓ Mandatory
2. Symmetry: $(a,b) \implies (b,a)$ ✓ Mandatory
3. Transitivity: $(a,b) \land (b,c) \implies (a,c)$ ✓ Mandatory
Standard Board Theorems:
• Smallest equivalence relation on $A$: The Identity Relation $I_A$.
• Largest equivalence relation on $A$: The Universal Relation $A \times A$.
• If $R_1, R_2$ are equivalence relations on $A$, then $R_1 \cap R_2$ is always an equivalence relation!
Note: The union $R_1 \cup R_2$ need NOT be an equivalence relation (transitivity may fail!).
Equivalence Classes & Partition of Set $\mathbb{Z}$
Congruence Modulo $m$: $a \equiv b \pmod m \iff m \mid (a - b)$

✓ Fundamental Theorem of Equivalence Relations:

Any equivalence relation partitions a set into pairwise disjoint equivalence classes whose union is the whole set: $\bigcup [a] = A$ and $[a] \cap [b] = \emptyset$ whenever $[a] \neq [b]$.

Equivalence class definition: $[a] = \{x \in A : (x, a) \in R\}$. • Santanu Sir
